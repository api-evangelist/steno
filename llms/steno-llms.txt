# Steno

> Steno (Steno Agency, Inc., Los Angeles, CA) is a legal technology and litigation
> services company serving 1,200+ US law firms with court reporting, remote and hybrid
> depositions, legal videography, interpreting, and record retrieval. Its software
> products are Steno Connect for Zoom, Firm Dashboard, Transcript Genius, and DelayPay.
> Steno operates no public developer program. Its integration surface is distributed
> through host platforms — a Salesforce AppExchange managed package for Litify, a Clio
> App Directory listing for Clio Manage, and a Zoom App — each authenticated with an
> organization-scoped API key that Steno issues on request. No OpenAPI, AsyncAPI,
> GraphQL SDL, MCP server, or A2A agent card is published at any reachable location.

This file was generated by API Evangelist from public sources. Steno does not publish
its own /llms.txt (https://steno.com/llms.txt returns 404).

## APIs

- [Steno Integration API](https://help.steno.com/steno-litify-integration): Private,
  organization-scoped HTTP API behind Steno's first-party case-management integrations.
  Base host https://api.steno.com is a live AWS API Gateway that returns
  `{"message":"Forbidden"}` to every anonymous request. Credentials are an API key
  Steno generates per customer organization. No public reference exists.

## Specs

- None. Steno publishes no OpenAPI, Swagger, AsyncAPI, GraphQL SDL, JSON Schema, or
  Postman collection. See `well-known/steno-well-known.yml` in this repo for the full
  probe record of every location checked and the status each returned.

## Products

- [Steno Connect for Zoom](https://steno.com/technology/steno-connect): Zoom App for
  remote depositions, hearings, and bench trials with exhibit upload, sharing, and
  annotation.
- [Firm Dashboard](https://steno.com/technology/firm-dashboard): Scheduling, job
  management, file access, invoicing, SAML SSO, MFA, and role-based access control.
- [Transcript Genius](https://steno.com/technology/transcript-genius): AI-assisted
  transcript search, summarization, multi-transcript interrogation, and video clip
  cutting.
- [DelayPay](https://steno.com/services/delaypay): Deferred-payment financing for
  plaintiff firms.

## Integrations

- [Litify integration](https://steno.com/technology/litify-integration) — installed as
  a Salesforce managed package; book jobs and open transcripts, exhibits, and video
  from a Litify Matter record. Setup: https://help.steno.com/steno-litify-integration
- [Clio integration](https://steno.com/clio-integration) — book jobs and manage
  deposition files inside Clio Manage.
  Setup: https://help.steno.com/how-do-i-book-jobs-with-steno-on-clio-manage
